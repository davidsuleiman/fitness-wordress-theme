================================================================================
                           QUICK START GUIDE
================================================================================

STEP 1: Create Pages in WordPress
   1. Go to Pages > Add New
   2. Create these pages with these slugs:
      - /products (use elementor-product-coming-soon.html)
      - /contact (use elementor-contact-us.html)
      - /sponsors (use elementor-sponsor-us.html)
      - /blog (use elementor-blog-page.html)

STEP 2: Add Elementor HTML Widget
   1. Edit each page with Elementor
   2. Click "Add Element"
   3. Search for and add "HTML" widget

STEP 3: Paste HTML Code
   1. Open corresponding .html file
   2. Copy ALL code
   3. Paste into Elementor HTML widget

STEP 4: Replace Email Addresses
   Contact Page:
   - hello@redefineandco.com → your email
   - press@redefineandco.com → your press email
   - partnerships@redefineandco.com → your partnerships email
   
   Sponsor Page:
   - sponsorships@redefineandco.com → your sponsorship email

STEP 5: Publish Pages
   Click "Publish" to save
