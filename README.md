# ReDefine & Co. WordPress Theme

ReDefine & Co. is a three-page fitness blog theme inspired by the editorial structure of Fitt Insider: a text-led blog homepage, a compact products page, and a contact page.

## Install

1. Copy this folder into `wp-content/themes/redefine-co`.
2. In WordPress Admin, go to **Appearance > Themes** and activate **ReDefine & Co.**.
3. Create two pages:
   - **Products** using the **Products Page** template.
   - **Contact** using the **Contact Us Page** template.
4. Go to **Appearance > Menus** and add Blog, Products, and Contact to the Primary Menu.
5. Optional: set your site title and tagline under **Settings > General**.

## Files

- `index.php`: blog homepage and post listing.
- `page-products.php`: products landing page template.
- `page-contact.php`: contact page template.
- `single.php`: single article template.
- `style.css`: theme metadata and all theme styling.

The contact and newsletter forms are static HTML placeholders. Connect them to a form plugin, email service, or custom handler before using them in production.
